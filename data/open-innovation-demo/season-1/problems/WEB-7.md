## Problem Statement

Build a browser-based reporting workflow that lets students and staff submit maintenance issues even when connectivity is unreliable. The system should queue photo attachments, sync when the network returns, and keep each reporter informed about status changes.

## Expected Solution

Teams should propose a lightweight web application, a resilient sync strategy, and an operator dashboard for triage and assignment.

## Dataset

Synthetic building inventory and maintenance history: https://example.com/datasets/web-7.csv
